# Support

- Usage questions and ideas: [GitHub Discussions](https://github.com/stacking-money-forever/oh-my-dm/discussions)
- Reproducible bugs: [GitHub Issues](https://github.com/stacking-money-forever/oh-my-dm/issues/new/choose)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)

Before asking for help, run `oh-my-dm doctor`, search existing discussions and issues, and remove all personal information from logs and screenshots. KakaoTalk support is limited to macOS. Instagram and KakaoTalk UI changes may temporarily break integrations.

## 한국어

사용 질문과 아이디어는 Discussions, 재현 가능한 버그는 Issues를 이용해 주세요. 먼저 `oh-my-dm doctor`를 실행하고 기존 글을 검색해 주세요. 로그와 스크린샷에서는 개인정보를 반드시 제거해야 합니다. 보안 문제는 공개 issue가 아니라 [SECURITY.md](SECURITY.md)를 따라 주세요.
